# Frontend rules (Next.js 16)

## Framework

- Next.js 16 uses the App Router, with Turbopack as the default bundler. Request interception goes in **`proxy.ts`**; `middleware.ts` is the old name, so don't create it.
- Components are Server Components by default. Add `"use client"` only for interactivity, charts, stores and WS. Never import a server-only module into a client component.
- The browser talks **only** to the Next.js origin: `/api/*` and `/ws/*` are proxied to Django by the `next.config.ts` rewrites. Never hard-code `localhost:8000` in components.
- **No secrets in client code or `NEXT_PUBLIC_*`.** The browser never holds an API key, and the Anthropic key stays in the backend.

## Data and state

- **Tick-rate data never goes in React state.** Ticks, forming bars, live signals, health and pipeline events live in Zustand stores (ring buffers). Components subscribe with narrow selectors, and charts read them through `store.subscribe` outside React.
- Server state (history, ledgers, backtests, models, settings, advisor history) goes through TanStack Query hooks in `queries/`, built on the typed `lib/api.ts`. That client adds CSRF for you.
- Use one WebSocket per tab through `lib/ws-client.ts`, with ref-counted subscribe, reconnect + resubscribe, and seq-gap resync. Never open ad-hoc sockets.
- POST streaming (SSE for Ask Claude and narratives) uses `lib/sse.ts`. `EventSource` can't POST.

## Charts and visuals

- Price charts go **only through `components/charts/chart-core.ts`** (Lightweight Charts v5): imperative `series.update()` in a rAF loop capped at 30 fps. Custom overlays are primitives registered in `components/charts/primitives/`.
- Explainability charts use ECharts (`echarts-for-react`), loaded with `next/dynamic`. Plotly is lazy-loaded and kept off the symbol page.
- Import animation from `motion/react` (not `framer-motion`) and use `LazyMotion` with the shared variants in `lib/motion.ts`.

## UI conventions

- Use shadcn/ui components in `components/ui/` and Tailwind v4 theme tokens (CSS variables for light/dark). Don't hard-code colours.
- Format prices with `lib/format.ts` using `symbol.digits`. Times come in UTC and are shown in local time with the zone visible.
- Wrap `localStorage` in try/catch, and use it only for UI preferences.
- Only ask for browser notification permission from Settings, never on page load.

## Generated code

- `lib/contracts/*` is generated by `just contracts`. **Never edit it.**
